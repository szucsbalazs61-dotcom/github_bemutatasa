Alapfogalmak

Mi az a GitHub és miben más, mint a Git?

Sokan összekeverik a Git-et és a GitHubot. Bár szorosan összefüggenek, teljesen eltérő feladatot látnak el a szoftverfejlesztésben.

Git

Helyi Verziókezelő Szoftver
  • A saját számítógépeden futó parancssori eszköz.
  • Nyomon követi a fájlok változásait és a kód históriáját.
  • Működik internetkapcsolat nélkül is offline módban.

GitHub

M felhőalapú Tároló & Platform
  • Felhőben tárolja a Git repository-kat (projekt raktárakat).
  • Közösségi funkciókat, code review-t, és projektmenedzsmentet nyújt.
  • Beépített AI (Copilot), automatizáció (Actions) és webes felület.
Felhőtárhely (Cloud Hosting)

A kódod biztonságban van a felhőben. Bárhonnan elérheted, nem veszik el, ha meghibásodik a számítógéped.

Nyílt Forráskód & Közösség

Milliónyi nyílt forráskódú projekthez (Open Source) csatlakozhatsz, tanulhatsz mások kódjából vagy hozzájárulhatsz.

Csapatmunka (Collaboration)

Több fejlesztő dolgozhat ugyanazon a projekten egyidejűleg anélkül, hogy felülírnák egymás munkáját.

Ökoszisztéma

A GitHub Fő Funkciói

Minden eszköz egy helyen, amire egy modern szoftverfejlesztő csapatnak szüksége lehet.

Projekt Tárolók

Repositories (Raktárak)

A repository (röviden „repo”) a projekted központi mappája. Tartalmazza az összes fájlt, a fájlok módosítási előzményeit (commit history), a README leírást és a licencet.

  • ✓ Nyilvános (Public) vagy Privát (Private) láthatóság
  • ✓ Beépített Wikik és dokumentáció
  • ✓ Branch védelem és jogosultságkezelés

Kódellenőrzés & Egyesítés

Pull Requests (PR)

A Pull Request a GitHub együttműködés lelke. Lehetővé teszi, hogy javaslatot tegyél a kód módosítására, amit a csapattársaid átnézhetnek (Code Review), megjegyzéseket fűzhetnek hozzá, majd egyesíthetik (Merge) a fő kóddal.

  • ✓ Vizuális diff (változások sorról sorra)
  • ✓ Kötelező jóváhagyások (Approvals)
PR #42: + Add user authentication
+ const user = await auth.login(credentials);
- const user = oldAuthSystem.login();
Reviewer: @senior_dev Approved

GitHub Copilot

A te AI pár-programozód! Valós időben egészíti ki a kódodat, funkciókat generál kommentek alapján, megmagyarázza a komplex kódokat és segít a hibakeresésben.

// Függvény, ami kiszámolja a faktoriálist
function calculateFactorial(n) {
// Copilot által kiegészített kód:
if (n === 0 || n === 1) return 1;
return n * calculateFactorial(n - 1);
}

Az Alapvető Git & GitHub Munkafolyamat

Így kerül a helyi számítógépeden írt kód a GitHub felhőjébe 4 egyszerű lépésben.

1

git init

Munkamenet / projekt inicializálása a helyi mappában. A Git megkezdi a fájlok követését.

$ git init
2

git add

Módosítások előkészítése a mentésre (Staging Area). Meghatározod, mi kerüljön bele a commitba.

$ git add .
3

git commit

Pillanatkép (snapshot) készítése a kód állapotáról egy leíró üzenettel ellátva.

$ git commit -m "üzenet"
4

git push

A helyi commitok feltöltése a távoli (Remote) GitHub szerverre, hogy mások is elérhessék.

$ git push origin main
